# 🚀 快速开始指南

## 1分钟上手EPUB翻译工具

### 第一步：获取OpenAI API Key

1. 访问 https://platform.openai.com/
2. 注册/登录账号
3. 前往 https://platform.openai.com/api-keys
4. 创建新的API Key（以`sk-`开头）
5. 复制并保存

### 第二步：打开应用

**方式1：直接打开（最简单）**
```bash
# 用浏览器直接打开
open index.html  # macOS
start index.html # Windows
xdg-open index.html # Linux
```

**方式2：本地服务器（推荐）**
```bash
# Python
python3 -m http.server 8000

# Node.js
npx http-server

# 然后访问 http://localhost:8000
```

### 第三步：配置API

1. 点击右上角 ⚙️ **设置**
2. 粘贴API Key
3. 选择模型（推荐 **GPT-4o-mini**，经济实惠）
4. 点击 **测试连接**
5. 点击 **保存设置**

### 第四步：翻译书籍

1. 📤 **拖拽** EPUB文件到上传区域
2. 👀 预览书籍内容和章节
3. 🚀 点击 **开始翻译**
4. ⏳ 等待翻译完成（可实时查看进度）
5. 📥 点击 **下载译文**

## 💰 成本参考

### GPT-4o-mini（推荐）
- 10万字小说：约 $0.03 - $0.05
- 30万字小说：约 $0.10 - $0.15

### GPT-4o（高质量）
- 10万字小说：约 $0.75 - $1.00
- 30万字小说：约 $2.25 - $3.00

## 🎯 翻译技巧

### 1. 选择合适的模型
- 📚 **小说、故事** → GPT-4o-mini（性价比高）
- 📖 **文学经典** → GPT-4o（质量更好）
- 📄 **技术文档** → GPT-4o-mini（足够准确）

### 2. 调整翻译风格
- **直译**：技术文档、说明书
- **意译**：小说、散文（默认推荐）
- **文学性**：诗歌、经典文学

### 3. 优化成本
- 使用 **GPT-4o-mini** 模型
- 只翻译需要的章节
- 先翻译一章预览质量

## ⚠️ 注意事项

1. **API Key安全**
   - 仅保存在浏览器本地
   - 不要分享给他人
   - 定期更换

2. **翻译时间**
   - 10万字约 8-10 分钟
   - 不要关闭浏览器标签页
   - 可随时暂停/继续

3. **文件大小**
   - 建议 < 10MB
   - 最大 50MB
   - 太大的文件可能导致浏览器卡顿

## 🆘 常见问题

### API连接失败？
- 检查API Key是否正确（以`sk-`开头）
- 检查OpenAI账户是否有余额
- 检查网络连接是否正常

### 翻译质量不佳？
- 尝试切换到GPT-4o模型
- 调整翻译风格设置
- 检查原文是否清晰

### 浏览器卡顿？
- 关闭其他标签页
- 使用Chrome或Edge浏览器
- 文件太大时分章节翻译
