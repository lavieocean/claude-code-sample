## 🚀 快速开始

### 第一步：获取 Gemini API Key

1. **访问 Google AI Studio**
   - 地址：https://aistudio.google.com/app/apikey

2. **登录 Google 账号**
   - 使用任何Google账号即可（Gmail等）

3. **创建 API Key**
   - 点击 "Create API Key" 或"获取API密钥"
   - 选择一个Google Cloud项目（或创建新项目）
   - 复制生成的API Key（格式：`AIza...`）

4. **保存API Key**
   - API Key立即可用，无需等待
   - 记得保管好，不要泄露

### 第二步：在工具中配置

1. 打开 EPUB Translator
2. 点击右上角 **⚙️ 设置**
3. 在"选择引擎"下拉框中选择 **Google Gemini**
4. 粘贴您的API Key（AIza开头）
5. 选择模型：
   - **Gemini 1.5 Flash**（推荐）- 免费，快速
   - **Gemini 1.5 Pro** - 高质量，免费额度少
   - **Gemini 2.0 Flash** - 实验性，最新模型
6. 点击 **测试连接** 验证
7. 点击 **保存设置**

### 第三步：开始翻译

1. 上传EPUB文件
2. 点击 **开始翻译**
3. 享受免费高质量翻译！

## ⚠️ 使用注意事项

### 1. 速率限制

**问题：** "429 Too Many Requests" 错误

**原因：** 请求过快，超过了速率限制

**解决方案：**
- 工具已内置200ms延迟
- 如仍然出现，可以暂停翻译，等待1-2分钟后继续

### 2. 免费额度用完

**问题：** 达到每日上限

**解决方案：**
- 等待第二天重置（太平洋时间凌晨）
- 或升级到付费版本（价格非常低）

### 3. API Key 安全

**注意事项：**
- 不要在公共场合分享API Key
- API Key仅保存在本地浏览器
- 可以在Google AI Studio随时撤销密钥

## 📝 最佳实践

### 1. 优化翻译质量

**技巧：**
- 选择合适的翻译风格（意译/直译）
- 对于文学作品，选择"文学性翻译"
- 对于技术文档，选择"忠实原文"

### 2. 最大化免费额度

**策略：**
- 使用 Gemini Flash 而不是 Pro
- 避免重复翻译同一内容
- 合理安排翻译时间，避免突破速率限制

### 3. 混合使用引擎

**方案：**
- 日常书籍：Gemini Flash（免费）
- 重要章节：Gemini Pro（高质量）
- 特殊需求：OpenAI GPT-4o（最高质量）

## 🛠️ 故障排除

### 问题1：API Key无效

**检查：**
- API Key格式正确（AIza开头）
- 在Google AI Studio中密钥状态正常
- 网络连接正常

### 问题2：翻译速度很慢

**可能原因：**
- 网络延迟
- 达到速率限制

**解决：**
- 检查网络连接
- 暂停后继续翻译

### 问题3：翻译质量不佳

**改进方法：**
- 切换到 Gemini Pro 模型
- 调整翻译风格设置
- 尝试不同的prompt设置
