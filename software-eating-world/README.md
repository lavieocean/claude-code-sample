# 软件如何吞噬世界 | Software Eating the World

一个精美的交互式网站，展示软件技术如何逐步改变各个行业和领域。

## 项目概述

本项目通过视觉化的时间线、互动图表和数据展示，呈现Marc Andreessen提出的"软件正在吞噬世界"这一著名论断。网站展示了从2000年至今，软件和数字技术如何颠覆传统行业。

## 主要特性

### 📅 技术演进时代
展示四个关键时代的技术里程碑：
- **2000年之前** - 个人计算机时代
- **互联网诞生** - Web 1.0时代
- **Web 2.0** - 云计算与社交时代
- **移动互联网** - 万物互联时代

### 🏢 行业数字化演进
涵盖8个主要行业的数字化转型历程：
- 零售 (95%数字化)
- 媒体娱乐 (90%数字化)
- 交通出行 (85%数字化)
- 金融服务 (88%数字化)
- 教育 (70%数字化)
- 医疗健康 (65%数字化)
- 农业 (45%数字化)
- 制造业 (75%数字化)

### 💡 投资洞见
整合a16z和Sequoia Capital的投资视角：
- 软件优势与颠覆路径
- 市场时机与创始人DNA
- 重点投资领域分析
- 市值增长数据可视化

### 🔮 未来展望
探索下一个十年的趋势：
- AI原生应用
- Web3与去中心化
- 生物与软件融合
- 气候科技

3. 无需额外依赖或构建步骤

## 核心洞察

### a16z观点
> "软件正在吞噬世界。在未来10年，几乎每个行业都将被软件公司重塑。" - Marc Andreessen

**关键要点：**
- 软件的零边际成本优势
- 从利基市场到主流的颠覆路径
- 网络效应和数据护城河
- AI加速软件吞噬进程

### Sequoia Capital观点
> "伟大的公司在市场转折点诞生。软件与AI的结合正创造下一个黄金时代。"

**关键要点：**
- 技术成熟度与市场需求的交汇
- 深度理解行业的创始人
- 从工具到生态的演进
- 构建10年以上的竞争优势
