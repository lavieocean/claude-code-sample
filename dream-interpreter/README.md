# ✨ 梦境解读应用

一个精美的、基于 React 的解梦应用，使用 Claude AI 来分析和解读你的梦境。

![Dream Interpreter](https://img.shields.io/badge/React-18.3-blue)
![Vite](https://img.shields.io/badge/Vite-7.2-purple)
![Anthropic](https://img.shields.io/badge/Claude-AI-orange)

## ✨ 特性

- 🌙 **记录梦境**: 轻松记录你的梦境标题和详细内容
- 🤖 **AI 解读**: 使用 Claude AI 提供深入、温暖的梦境分析
- 💾 **本地存储**: 所有梦境数据安全地存储在浏览器本地
- 🎨 **精美设计**:
  - 动态渐变背景
  - 流畅的动画效果
  - 玻璃态卡片设计
  - 响应式布局
- 🔒 **隐私保护**: 你的 API Key 和梦境数据只存储在你的浏览器中

## 🎨 设计特色

- **梦幻渐变背景**: 使用多色渐变和动画创造平静、冥想般的氛围
- **玻璃态卡片**: 半透明的卡片设计配合模糊效果
- **流畅过渡**: 所有交互都有精心设计的动画
- **温暖的配色**: 紫色、蓝色、粉色的和谐搭配

## 📖 使用指南

### 1. 设置 API Key

首先，你需要一个 Anthropic API Key：

1. 访问 [Anthropic Console](https://console.anthropic.com/)
2. 创建一个新的 API Key
3. 在应用的第一个卡片中输入你的 API Key
4. API Key 会安全地存储在浏览器的 localStorage 中

### 2. 记录梦境

1. 在"梦境标题"字段中输入一个描述性的标题
2. 在"梦境内容"区域详细描述你的梦境
   - 包括场景、人物、情绪和感受
   - 越详细越好，这样 AI 能提供更准确的解读
3. 点击"记录并解读梦境"按钮

### 3. 查看解读

- 如果你已设置 API Key，AI 会自动开始解读你的梦境
- 解读过程通常需要几秒钟
- 解读完成后，你会看到一个详细的分析，包括：
  - 梦境的象征意义
  - 可能反映的情绪状态
  - 与现实生活的联系
  - 积极的启示和建议

### 4. 管理梦境

- **展开/折叠**: 点击梦境内容查看完整文本
- **手动解读**: 如果某个梦境还没有解读，点击 ✨ 按钮
- **删除**: 点击 🗑️ 按钮删除不需要的梦境

## 📝 注意事项

### API 使用

- 应用使用 `dangerouslyAllowBrowser: true` 允许在浏览器中直接调用 API
- **重要**: 在生产环境中，建议通过后端服务器调用 API 以保护你的 API Key
- 每次解读会消耗 API 额度，请注意使用量

### 数据隐私

- 所有梦境数据存储在浏览器的 localStorage 中
- 清除浏览器数据会删除所有梦境记录
- API Key 也存储在 localStorage 中
- 建议不要在公共电脑上使用
