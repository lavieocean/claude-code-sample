# 🌍 交互式语言学习导师

一个智能的、交互式的语言学习平台，支持多种语言学习，提供实时反馈、个性化学习目标和进度追踪。

## 核心功能

### 📚 多语言支持
- 🇪🇸 西班牙语
- 🇫🇷 法语
- 🇩🇪 德语
- 🇯🇵 日语
- 🇮🇹 意大利语
- 🇵🇹 葡萄牙语
- 🇷🇺 俄语
- 🇰🇷 韩语

### 💬 智能对话系统
- **AI 驱动的对话**：使用 Google Gemini API 生成自然、上下文相关的回复
- **双模式学习**：
  - 休闲聊天模式：自由对话，轻松练习
  - 结构化课程模式：系统化教学，包含例句和练习
- **上下文感知**：根据对话历史提供连贯的回复

### 📝 实时反馈系统
- 自动分析语法、词汇和句法
- 在侧边面板中显示实时反馈
- 温和的纠正建议，不打断对话流程
- 正面鼓励，激励持续学习

### 🎯 个性化学习目标
- 自动识别用户熟练程度（初学者、基础、中级、高级、流利）
- 根据学习进度自动生成学习目标
- 支持手动添加/编辑自定义目标
- 目标完成自动检测

### 📊 进度追踪与可视化
- **实时统计**：
  - 词汇量增长
  - 对话消息数
  - 学习时长
- **可视化图表**：直观的柱状图展示学习进度
- **学习日志**：自动记录每次学习会话

### 🎨 用户界面特点
- 简洁直观的现代化设计
- 清晰分离的对话区域和反馈区域
- 完全响应式，支持手机、平板和桌面设备
- 流畅的动画和过渡效果
- 熟练程度可视化指示器

## 使用方法

### 快速开始

#### 方式一：演示模式（推荐体验）🎭

1. **打开应用**
   ```bash
   在浏览器中打开 language-tutor.html
   ```

2. **启用演示模式**
   - 首次打开时，应用会自动进入演示模式
   - 或点击"🎭 体验演示模式"按钮
   - **无需 API Key** 即可体验所有功能！

3. **开始对话**
   - 默认语言：日语
   - 尝试输入以下示例：
     - "你好" - 学习基本问候
     - "我想学习食物词汇" - 了解食物相关表达
     - "こんにちは" - 用日语交流
   - 查看右侧面板获取实时反馈

4. **切换语言**
   - 演示模式支持：🇯🇵 日语、🇪🇸 西班牙语、🇫🇷 法语、🇩🇪 德语
   - 每种语言都有丰富的预设对话场景

#### 方式二：AI 模式（真实对话）🤖

1. **打开应用**
   ```bash
   在浏览器中打开 language-tutor.html
   ```

2. **设置 API Key**
   - 点击"切换到 AI 模式"
   - 输入你的 Google Gemini API Key
   - 获取 API Key：访问 [Google AI Studio](https://makersuite.google.com/app/apikey)
   - API Key 将安全地保存在浏览器本地存储中

3. **选择学习语言**
   - 支持所有 8 种语言
   - 从顶部下拉菜单选择你想学习的语言

4. **开始对话**
   - 在输入框中输入你的消息
   - AI 导师会用目标语言回复你
   - 查看右侧面板获取实时反馈和学习建议

# 🎹 MIDI 电子琴

一个基于Web的交互式MIDI电子琴应用，支持键盘演奏、八度切换和多种音色选择。

## 功能特点

- 🎹 **完整的12键一个八度键盘**（7个白键 + 5个黑键）
- ⌨️ **键盘控制**：
  - 白键：`A` `S` `D` `F` `G` `H` `J` (对应 C D E F G A B)
  - 黑键：`W` `E` `T` `Y` `U` (对应 C# D# F# G# A#)
- 🎵 **八度切换**：支持0-8个八度范围（默认第4八度）
- 🎨 **3种合成器音色**：
  - 正弦波 (柔和)
  - 方波 (明亮)
  - 锯齿波 (丰富)
- 🖱️ **鼠标支持**：可以直接点击钢琴键演奏
- 📱 **响应式设计**：支持移动设备

## 使用方法

### 在线使用

1. 用浏览器打开 `index.html` 文件
2. 点击页面任意位置或按任意键以启用音频
3. 开始演奏！

### 演奏指南

#### 键盘映射

```
黑键:  W   E       T   Y   U
白键: A  S  D  F  G  H  J
音符: C  D  E  F  G  A  B
```

#### 控制说明

- **演奏音符**：按下对应的键盘按键或点击屏幕上的琴键
- **切换八度**：点击 `+` 或 `-` 按钮来升高或降低八度
- **更换音色**：从下拉菜单中选择不同的合成器波形

## 技术实现

- **HTML5**：页面结构
- **CSS3**：样式和动画效果
- **Web Audio API**：音频合成和播放
- **原生JavaScript**：应用逻辑（无需外部依赖）

## 开发说明

### 音频引擎

应用使用 Web Audio API 创建合成器音色。每个音符通过以下方式生成：

1. **振荡器 (Oscillator)**：生成基础波形
2. **增益节点 (Gain Node)**：控制音量
3. **ADSR 包络**：Attack-Decay-Sustain-Release 音量包络

### 频率计算

基准音符为 A4 = 440Hz，其他音符频率通过等程律计算：
```
frequency = baseFrequency × 2^(octave - 4)
```
