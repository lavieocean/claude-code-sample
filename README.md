# MIDI 电子琴

一个基于Web的交互式MIDI电子琴应用，支持键盘演奏、八度切换和多种音色选择。

## 功能特点

- 🎹 **完整的12键一个八度键盘**（7个白键 + 5个黑键）
- ⌨️ **键盘控制**：
  - 白键：`A` `S` `D` `F` `G` `H` `J` (对应 C D E F G A B)
  - 黑键：`W` `E` `T` `Y` `U` (对应 C# D# F# G# A#)
- 🎵 **八度切换**：支持0-8个八度范围（默认第4八度）
- 🎨 **3种合成器音色**：
  - 正弦波 (柔和)
  - 方波 (明亮)
  - 锯齿波 (丰富)
- 🖱️ **鼠标支持**：可以直接点击钢琴键演奏
- 📱 **响应式设计**：支持移动设备

## 使用方法

### 在线使用

1. 用浏览器打开 `index.html` 文件
2. 点击页面任意位置或按任意键以启用音频
3. 开始演奏！

### 演奏指南

#### 键盘映射

```
黑键:  W   E       T   Y   U
白键: A  S  D  F  G  H  J
音符: C  D  E  F  G  A  B
```

#### 控制说明

- **演奏音符**：按下对应的键盘按键或点击屏幕上的琴键
- **切换八度**：点击 `+` 或 `-` 按钮来升高或降低八度
- **更换音色**：从下拉菜单中选择不同的合成器波形

## 开发说明

### 音频引擎

应用使用 Web Audio API 创建合成器音色。每个音符通过以下方式生成：

1. **振荡器 (Oscillator)**：生成基础波形
2. **增益节点 (Gain Node)**：控制音量
3. **ADSR 包络**：Attack-Decay-Sustain-Release 音量包络

### 频率计算

基准音符为 A4 = 440Hz，其他音符频率通过等程律计算：
```
frequency = baseFrequency × 2^(octave - 4)
```
